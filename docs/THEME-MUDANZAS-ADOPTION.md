# theme-mudanzas adoption

This repository consumes the canonical `theme-mudanzas` contract defined by the Mudanzas ecosystem.

## Product role
Planning/tool layer: help users understand, calculate and prepare before contacting a provider.

## Adoption boundary
Shared visual primitives may converge. Product content, routes, calculator logic, lead handling, SEO metadata and primary journey remain local.

## QA
Any change that alters rendered UI requires automated technical QA first and a UI/UX HUMAN GATE only after technical PASS.
